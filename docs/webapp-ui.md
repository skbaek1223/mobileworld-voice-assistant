# 밥마중 휴대폰 웹앱 — 화면(UI)

이 문서는 휴대폰 웹앱의 **화면을 어떻게 만들었는지** 설명합니다. 음성 쪽(마이크, 자동 안내, 서버 구조, 실행 옵션)은
[voice-assistant.md의 휴대폰 웹앱](voice-assistant.md#휴대폰-웹앱-안드로이드아이폰)에 있습니다.

## 기본 원칙

- **원본 화면을 고치지 않습니다.** 화면은 jiminj0420의 늘밥 웹 프로토타입(`NEULBAB_APP_DIR`) 그대로입니다.
  원본 파일은 저장소에 복사하지도, 수정하지도 않습니다. 서버가 파일을 내보낼 때 글자를 바꾸고 CSS를 덧붙입니다(`webapp/server.py`의 `restyle_page`, `restyle_text`).
- 바꾸는 것은 세 가지입니다. ① 이름(늘밥 → 밥마중) ② 모양(시안 B, 홍시색 테마) ③ 앱처럼 쓰기 위한 몇 가지 동작(한 번 눌러 들어가기, 자동 초기화 등).
- 원본의 고령자 UI 규칙은 그대로 지킵니다. **글자 22px 이상, 버튼 60px 이상, 간격 24px.**
- 음성 위젯(마이크·자막)은 Shadow DOM 안에 있어서 화면 스타일과 섞이지 않습니다(`static/widget.css`).

```
휴대폰 ── GET parent.html ──> server.py ── NEULBAB_APP_DIR에서 원본 읽기
                                   │  이름 바꾸기, theme.css 덧붙이기, 머리줄 로고,
                                   │  어르신 메뉴 3개씩, 남은 시간 줄, 위젯 스크립트
                                   └──> 고친 HTML/JS (no-cache, ?v=버전)
```

## 디자인: 시안 B · 홍시색

2026-11-05에 두 시안 중 **B안(메뉴를 큰 사진 카드로 보여 주는 안)** 을 골랐습니다. 원본 첫 화면의 A/B 고르기("화면 디자인을 바꿔 볼 수 있어요")는 지우고, 항상 B안으로 엽니다.

색은 `static/theme.css` 하나에 있고, 원본 `style.css` 바로 뒤에 붙습니다.

| 쓰임 | 색 | 이유 |
|---|---|---|
| 바탕 | `#FFF7EA` 한지 아이보리 | 흰 바탕보다 눈부심이 적음 |
| 주 색(버튼, 지금 단계) | `#C2410C` 홍시 | 흰 글씨 대비 5.2:1 |
| 가격·상태 글씨 | `#A8380A` | 아이보리 위 6.0:1 |
| 끝난 단계, 도착 | `#2E6B30` / `#1E4A2B` 초록 | "다 됐다"는 뜻 |
| 보조 버튼 | `#FFE7A3` 버터색 + 진한 글씨 | 흰 버튼보다 버튼처럼 보임 |
| 취소 버튼 | `#FDE2DE` 연분홍 + `#7A1712` 글씨 | 위험하지만 무섭지 않게 |
| 어르신 | `#F2A36B` 살구색 | 첫 화면 버튼, "어르신이 주문" 표시 |
| 보호자 | `#B5DCAF` 쑥색 | 첫 화면 버튼, "보호자가 대신 주문" 표시, "대신 주문하기" |

- **파랑·보라는 쓰지 않습니다.** 원본의 파랑·보라 상태 색도 홍시색·초록으로 바꿨습니다.
- 모든 글씨는 바탕과 대비 4.5:1 이상입니다.
- 버튼은 둥글고(20px) 아래 그림자가 있어 눌리는 버튼처럼 보이고, 누르면 내려갑니다.
- 연습용·데모 안내(연습용 카드, 지어낸 주소, 연습용 배달앱 문구 등)는 앱에서 보이지 않게 숨기거나 지웁니다.

## 이름과 앱 아이콘

- 화면·스크립트·manifest의 "늘밥"을 서버가 "밥마중"으로 바꿉니다. 예시 주소의 "늘밥구"는 지어낸 동네 이름이라 그대로 둡니다.
- 앱 아이콘은 **지붕 아래 밥그릇** 그림입니다(`static/app-icon*.png`, `app-icon.svg`, `brand.svg`). 홈 화면, 탭, 시작 화면, 머리줄 로고에 같은 그림을 씁니다.
- 홈 화면에 추가하면 주소창 없이 앱처럼 열립니다(manifest와 iOS용 meta 태그). 테마 색은 `#C2410C`입니다.

## 머리줄

- 위에 붙어 있는 흰 머리줄입니다(아이폰 노치 영역 `safe-area-inset-top`을 피함).
- 홈 화면에서는 **밥마중 로고**, 안쪽 화면에서는 **[뒤로]** 버튼이 같은 자리에 나옵니다.
- 화면 아래쪽은 160px를 비워 둡니다. 음성 자막 줄이 메뉴를 가리지 않게 하려는 것입니다.

## 첫 화면 (역할 고르기)

- 항상 이 화면에서 시작합니다. 원본의 데모 허브("누가 쓰실 화면인가요?")는 띄우지 않습니다.
- 환영 문구 대신 **"따뜻한 밥 한 끼, 가족이 챙겨 드려요"**.
- 버튼은 **[어르신] 먼저, [보호자] 다음**입니다. 버튼에는 이름만 있고 설명 줄은 없습니다.
- 버튼마다 72px 둥근 사람 그림이 있습니다. 어르신 버튼 = 할머니·할아버지 그림(`role-parent.svg`), 보호자 버튼 = 하트를 든 가족 그림(`role-guardian.svg`).
- **한 번 누르면 바로 들어갑니다.** 원본의 가족 번호 입력과 보호자 아이디·비밀번호, 회원가입 링크는 없앴습니다.
  어르신은 이 폰의 가족(여기서 보호자가 만든 가족, 없으면 예시 가족)으로, 보호자는 그 가족의 계정으로 들어갑니다.
- 한 폰에는 한 역할만 씁니다. "처음으로"를 누르면 이 화면으로 돌아옵니다.

## 어르신 화면

**메뉴 고르기**
- 제목: "어르신, 오늘 뭐 드실래요?" (다음 쪽은 "어르신, 이런 메뉴도 있어요"). 음성 안내도 이 제목을 읽기 때문에 문장을 어르신께 말하듯 썼습니다.
- **메뉴를 한 화면에 3개씩**, 사진이 큰 줄(96px 사진, 이름 28px, 가격 24px)로 보여 줍니다. 스크롤 없이 한눈에 보입니다. 줄 오른쪽 화살표는 누를 수 있다는 표시입니다.
- 아래에 **[앞 메뉴] [다른 메뉴 보기]** 를 한 줄로 둡니다. 첫 쪽에서는 [앞 메뉴]가 없습니다. 확인 화면에서 뒤로 오면 보던 쪽으로 돌아옵니다.
- 메뉴 사진은 실제 음식 사진입니다(`static/menus/m01~m12.jpg`, 출처는 `menus/credits.json`, `credits.html`). 사진이 없는 메뉴는 원본 그림을 씁니다.
- "다른 메뉴" 화면에서는 위쪽 [뒤로]를 숨기고, [뒤로]를 [다른 거 볼래요] 바로 옆에 붙였습니다. 손이 닿는 한 줄에 선택지가 다 있습니다.

**확인 화면**
- 제목 "어르신, 이 메뉴는 어떠세요?" 계열. 사진을 화면 폭으로 크게(높이 200px) 보여 줍니다.

**주문 상태**
- 단계를 원본의 무지개색 세로 막대 대신 **택배 조회처럼 가로 한 줄**로 보여 줍니다.
  - 지난 단계: 초록 테두리 + 체크 표시
  - 지금 단계: 크게(80px) + 홍시색 테두리
  - 남은 단계: 흐린 회색
  - 단계 사이를 선으로 이어 진행이 보입니다. 도착하면 지금 단계도 초록입니다.
  - "끝"/"지금" 글자는 화면에서 숨기지만 화면 읽기 프로그램은 읽습니다.
- 상태 문장 바로 아래에 **남은 시간**을 홍시색 상자에 크게(26px) 보여 줍니다: "약 12분 뒤 도착해요", "1분 안에 도착해요". 보호자 화면에도 같습니다.
- 언제 주문했는지, 이미 끝난 주문인지도 상태 문장에 나옵니다.
- 누가 주문했는지 상자는 첫 화면 버튼과 같은 색입니다(어르신 직접 = 살구색, 보호자 대신 = 쑥색).
- 취소 안내는 "취소할 수 없어요"만 남기고 "자녀분께 연락해 주세요"는 지웠습니다.
- **알아서 처음으로 돌아갑니다.** 도착하고 30초 뒤, 또는 다른 곳(음성, 보호자)에서 받았다고 확인하면 메뉴 고르기 화면으로 돌아갑니다.

## 보호자 화면

- 원본 보호자 화면에 같은 테마를 씌웁니다.
- 어느 배달앱으로 주문했는지 줄은 **노란 상자**(`#FFE08A`)로 눈에 띄게 했습니다.
- [대신 주문하기]는 "내가 대신 주문했어요"와 같은 쑥색입니다.
- 보호자 화면에는 **마이크·자막이 없습니다.** 위젯은 주문·설정을 맞추는 일만 합니다. 어르신이 말로 주문하면 보호자 화면도 바뀝니다.

## 음성 위젯의 모양

음성 동작은 [voice-assistant.md](voice-assistant.md#휴대폰-웹앱-안드로이드아이폰)에 있고, 여기서는 모양만 적습니다(`static/widget.css`).

- 오른쪽 아래에 84px 둥근 **마이크 버튼**. 평소 홍시색, 듣는 중에는 초록으로 깜박임, 처리 중에는 회갈색.
  버튼 아래 글자: "말하기" / "듣는 중" / "켜기"(자동 듣기를 껐을 때).
- 마이크 왼쪽에 **자막 줄**이 붙습니다. 메뉴 위에 크게 뜨는 말풍선 대신, 마이크가 이미 차지한 아래쪽 띠만 씁니다.
  비서가 한 말(22px 굵게, 최대 4줄), 들은 말, 상태가 나오고, 저절로 사라집니다.
- 확인 질문에는 자막 안에 큰 **[네] [아니요]** 버튼(높이 60px, 글자 24px)이 나옵니다.
- 어르신 화면에 처음 들어오면 화면 전체를 덮는 **"눌러서 시작하기"** 버튼(220px 높이, 글자 34px)이 한 번 나옵니다. 브라우저가 누르기 전에는 소리를 막기 때문입니다.

## 휴대폰에서 옛 화면이 남지 않게

- 고친 파일은 `Cache-Control: no-cache`로 내보냅니다.
- 페이지가 부르는 스크립트·스타일·그림 주소에 서버를 켤 때마다 바뀌는 버전(`?v=…`)을 붙입니다. 아이폰 홈 화면 앱은 캐시를 오래 붙잡고 있어서 필요합니다.
- `theme.css` 같은 정적 파일은 저장하면 바로 반영되고, `server.py`를 고치면 서버를 다시 켜야 합니다.

| `webapp/static/menus/` | 음식 사진과 출처(`credits.json`) |
